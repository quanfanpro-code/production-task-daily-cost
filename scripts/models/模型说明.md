# 本地方向模型

模型文件：`rapid_orientation.onnx`，约 6.4 MB。

发布来源：RapidAI / RapidOrientation 的 `v0.0.0` 发布资产 `rapid_orientation_models_v2.zip`。

下载地址：https://github.com/RapidAI/RapidOrientation/releases/download/v0.0.0/rapid_orientation_models_v2.zip

项目来源：https://github.com/RapidAI/RapidOrientation

训练来源：PaddleClas 四方向分类模型。运行无需安装飞桨，使用本机 ONNX Runtime 的 CPU 执行。

完整性 SHA256：

```text
2f62c9bfb830a0b417241269fde7ef2d0ad5446c0ed2b8af33b1f6543545e8e2
```

模型内标签顺序：0、90、180、270，表示输入文字顺时针偏转角；纠正角度是其反向。

预处理依据 RapidOrientation，采用 BGR、短边 256、224 裁切和 ImageNet 均值标准差。项目增加确定性多区域比较、不确定保留以及转正复查，不使用原项目无变化的重复中心裁切投票。
